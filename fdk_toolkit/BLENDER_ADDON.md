# FDK Blender 插件

插件 **FDK 模型与材质预览**，版本 **1.2.1**，适用 **Blender 4.5 LTS**。用于浏览 FDK 资源工具已导出的模型、恢复材质连接和创建预览相机与灯光。

从 [Release 下载页](https://github.com/Reguluz/FDKGraphicExporter/releases/latest) 获取工具合集内的 `fdk_toolkit/FDK_Blender_Addon.zip`，或单独下载 `FDK_Blender_Addon-v1.2.1.zip`。安装无需编译。插件包不包含游戏模型或贴图，也不嵌入构建者的本机路径；安装后需选择自己的配置文件或资源库。完整导出流程见 [首页操作说明](https://github.com/Reguluz/FDKGraphicExporter/blob/v1.2.1/README.md)。

## 安装与升级

1. 保存当前 Blender 工程。已有旧 Kuro II 插件时先禁用旧版。
2. 在 Blender「编辑 → 偏好设置 → 插件」中，从右上角菜单选择「从磁盘安装」，选择上面下载的插件 ZIP，不必解压。
3. 搜索并启用 **FDK 模型与材质预览**。
4. 展开插件偏好，将「游戏配置文件」设为工具合集解压目录内的 `fdk_toolkit/profiles.json`，保存偏好设置。也可不选配置，直接使用「默认导出目录」或侧栏中的自定义目录。
5. 升级后重启 Blender；在 3D 视图按 **N → FDK** 打开工具。

内部模块名仍为 `kuro2_preview`，场景属性也沿用旧名称，以兼容已有工程。这是同一插件的升级，不要同时启用两份；名称保留不表示插件只支持《黎之轨迹 II》。

## 选择资源库与导入

1. 已指定 `profiles.json` 时，在「游戏资源库」选择已配置的游戏；也可选择「自定义目录」，浏览自己的导出根目录。
2. 导出根目录应包含 `fbx`、`textures`、`materials`、`gltf`、`reports` 等内容。不要选择游戏安装目录、工具合集根目录或单独的 `fbx` 子目录。
3. 点击「刷新模型列表」，搜索资源 ID 并选择模型，再点击「导入模型并恢复材质」。列表只显示具有 FBX 和材质记录的可预览模型。
4. 默认创建预览相机和灯光。「灯光与法线」显示常规材质，「纯色贴图」便于检查贴图和 UV。

安装插件不会自动导出游戏资源。列表为空或缺少目标模型时，先在 FDK 导出窗口扫描并导出所需模型，再刷新列表。

导入前保持物体模式。切换资源库只改变列表，不删除场景中的模型；重复导入会产生新副本。隔离开关只影响插件管理的模型集合。

## 操作已导入模型

先选中目标模型对象，再使用「重建当前模型材质」「重建预览灯光与相机」「切换骨架透视显示」。面板显示当前对象所属游戏和模型 ID。

- 切换材质模式后，点击「重建当前模型材质」使新模式生效。
- 插件会拒绝把一个游戏的模型绑定到另一个游戏的同名贴图。出现资源库不匹配提示时，切回目标模型所属游戏。
- 移动同一游戏的完整导出目录时保留 `asset_profile.json`，选择新目录后重建材质可重新连接贴图。旧工程缺少身份记录时，插件依据原目录的身份文件或配置确认来源；无法确认时不会跨目录猜测绑定。
- 「保存为默认目录」保存下次启动时使用的资源库。
- 「保存预览工程」写入当前模型原资源库的 `previews` 文件夹。按 F12 渲染后，可在 Blender 图像菜单另存为图片。

## 材质与功能边界

插件按当前资源库的 `reports/shader_slots.json` 读取槽位语义，按模型真实材质引用连接贴图。不同游戏的资源库应完整、独立保存，不能混合复制同名模型或贴图。

PNG 的 RGBA 按独立通道加载，避免把打包在 Alpha 中的数据误用于预乘 RGB，导致面部颜色出现黑块；显式透明材质仍按相应 Alpha 连接处理。旧工程升级后点击「重建当前模型材质」即可应用当前读取方式。已包含中文界面下的节点名称兼容处理。

角色模型保留骨架和蒙皮。预览不等于完整原游戏着色器，当前不包含动画轨道、游戏 IK、头发或布料动态。特殊遮罩、TOON 和环境映射等输入保留为参考节点；缺图和未匹配材质在面板中显示。

配置文件不可访问时，请重新指定 `profiles.json` 或直接选择自己的导出目录。默认公开打包流程不携带可直接使用的本机资源路径。打包脚本的 `--local-paths` 选项仅用于个人本机安装包，会写入本机目录，不应用于公开分发。

## 错误记录

发生错误时，完整堆栈保存在 Blender 文本数据 `FDK_Error.txt` 和当前资源库的 `reports/blender_preview/last_error.txt`。这些是本地运行记录，不随源码发布。反馈问题时可提供去掉本机路径后的错误片段、Blender 版本和操作步骤，不附带游戏素材或完整资源库。
